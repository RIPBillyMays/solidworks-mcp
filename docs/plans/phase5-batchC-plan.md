## Global rules for every Batch C tool
1. Every member called must be ✅. The compat unit test enforces this.
2. Every create goes inside `dialogs_suppressed()`. Validate inputs before COM is touched, so a bad arg never reaches SW and raises a raw -2147417851.
3. **Success = measured delta, never a return value.** 2017 has five known silent no-ops (`EditMate4`, `EditRedo2`, `OverrideMass`, `InsertCombineFeature`, `PostSplitBody`). Each tool returns the feature-tree count before/after plus the measurement named below. "Returned a feature, no geometry change" is a FAIL.
4. Fence criteria (ADR-0006), the same for every item: fence when (a) a needed member is ❌ and no ✅ route builds it, or (b) after **2 credible attempts** in the live pass it no-ops, builds the wrong thing, or raises an unsuppressable modal. Fence = an entry in `sw2017_fences.py` with the reason and the attempt evidence.
5. Live work only in `sandbox/phase5/batchC/`. Fixture parts are generated by the live script, never opened from Zach's files.
